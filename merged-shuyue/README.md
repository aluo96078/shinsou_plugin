# Unified local fixture

Generated from `shinsou_plugin` and `shuyue_plugin`. Serve the parent directory with `python3 -m http.server 18081 --directory /Users/aluoexpiry/project/shinsou_plugin` and add `http://127.0.0.1:18081/merged-shuyue/` in Shinsou X.

This fixture contains the reviewed ShuYue novel extensions and legacy bytes required for existing
data migration. It is a test/migration fixture only; the installable repository is the v2 package
at the project root, and no v1 package is published from this directory.
